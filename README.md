# newsletter-inspiration-execution

Newsletter Agent: From Topic Brainstorm to Draft

## What is included

This repository now contains a lightweight static tool for newsletter teams who:

- send newsletters with Brevo
- want to extract lessons from previous issues
- want to track reply rate by issue
- need fresh topic ideas and first drafts automatically
- want reusable templates
- want a generated visual suggestion for each proposed issue

## How to use

Open `/home/runner/work/newsletter-inspiration-execution/newsletter-inspiration-execution/index.html` in a browser.

The app lets you:

1. paste an old newsletter and extract its subject/body
2. save reply rate, audience, and CTA for that issue
3. save draft templates with placeholders
4. generate new topic ideas based on the strongest reply-rate signals
5. create a draft from the selected template
6. preview and download a generated SVG cover suggestion

All data is stored locally in the browser with `localStorage`, so no backend setup is required.
